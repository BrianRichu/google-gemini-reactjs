# Google Gemini React Clone

A modern React + Vite project inspired by the Google Gemini interface. This app is designed as a sleek, AI-chat-style frontend clone with a clean layout, dark theme, and responsive design patterns similar to Gemini's user experience.

## Overview

This project is a front-end prototype for a Gemini-inspired assistant experience. It focuses on the UI and interaction design, making it a good foundation for building a chat application with AI features, prompt suggestions, and a polished user interface.

## Features

- Dark, modern UI inspired by Google Gemini
- Responsive layout for desktop and mobile screens
- Chat-style interface design
- Minimal, clean visual aesthetic
- React app structure with Vite for quick development
- Easy to extend for real API integration

## Tech Stack

- React

- JavaScript

## Getting Started

### Prerequisites

Make sure you have the following installed on your machine:

- Node.js (v18 or newer recommended)
- npm

### Installation

1. Open a terminal in the project root.
2. Navigate to the app folder:

```bash
cd gemini-clone
```

3. Install dependencies:

```bash
npm install
```

### Run the app

```bash
npm run dev
```

Then open the local URL shown in the terminal (usually http://localhost:5173).

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
